# 考研生物 · 知识卡片

浙江大学 830 生物化学与分子生物学 / 727 细胞生物学的背诵卡片站。

- **在线地址**：<https://elephenman.github.io/zju-bio-cards/>
- 单文件静态站，离线可用：把 `dist/index.html` 存到手机或本地直接打开即可。
- 卡片层级：栏目（学科）→ 专题 → 考点 / 章 → 题型分段（名词解释 / 问答题）→ 卡片。
- 交互：卡面先只给题干，点「显示答案」或按空格才展开作答，翻到下一张自动收起。
- 进度存在浏览器 `localStorage`，按栏目隔离，换设备不同步。
- 移动端优先，只有浅色一套主题。

## 内容口径

答案一律照录自个人使用的复习讲义与背诵笔记，不做自创改写；每条作答都要求能在原始资料里
定位到。页面上不混入答题提示、易错提醒、评分口径这类备考话术——那些属于统计信息，只以
角标形式呈现。站内不含任何图片版资料。

## 本仓库不包含什么

构建流水线、语料抽取件与答案库放在私有仓库外的本地目录里，本仓库只发布构建产物 `dist/`。
若要重建页面，需要本地的 `tools/` + `corpus/` + `docs/` 三套东西，它们不在此公开。
